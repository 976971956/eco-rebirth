# Bobcat / lynx reference provenance

- Title: `Bobcat`
- Creator: Poly by Google
- Source: https://poly.pizza/m/dKDEjAwfh0I
- License: Creative Commons Attribution 3.0 Unported
- Published: 2017-09-28
- Source listing: 666 triangles / 581 vertices, OBJ/GLTF
- Access checked: 2026-08-16

The production GLBs are generated by
`tools/blender/build_cinematic_lynx.py`. They retain the project's 22-bone
runtime contract while rebuilding the adult lynx's high-rumped felid body,
broad face, cheek ruff, tufted ears, short black-tipped tail and snowshoe paws.
The linked model is used only to cross-check silhouette and proportion.
