# 数据字典与初始平衡

## 1. 使用说明

本文数值用于 Godot 原型起步和自动测试，不代表最终发行平衡。所有值均应存入自定义 Resource，并由数据校验工具检查；脚本只实现公式，不为单一物种硬编码例外。

约定：

- 距离单位为米；
- 时间单位为秒；
- 角度在数据层使用度，运行时按 API 需要转换；
- 百分比在数据中使用 0–1；
- 体型级 1–5；
- 所有 ID 使用稳定英文 `StringName`，显示名独立本地化。

## 2. SpeciesData 字段

### 2.1 身份与资产

| 字段 | 类型 | 示例 | 规则 |
|---|---|---|---|
| `id` | StringName | `wolf_gray` | 全局唯一，发布后不随显示名变化 |
| `display_name_key` | StringName | `SPECIES_WOLF_GRAY` | 本地化键 |

| `portrait` | Texture2D | 图标 | HUD 与图鉴 |
| `body_size` | int | 3 | 1–5 |

| `habitat_tags` | Array | forest, grassland | 出生和适应性 |

## 8. 耐力和平衡公式

### 8.1 恢复

```text
实际恢复 = 基础恢复
         × 行动系数（静止1.0 / 步行0.7 / 其他0）
         × 饥饿系数（正常1.0 / 饥饿0.85 / 极饿0.65）
         × 天气系数
```

### 8.2 追逃基准

每个物种至少通过以下之一脱战：

- 速度优势能在 6–10 秒内拉开攻击距离；
- 耐力效率能让追击者先力竭；
- 技能制造至少 1.5 秒安全窗口；
- 专用地形通路使天敌不可达；
- 防御能拖到第三方介入，但不能无限无损耗。

自动测试记录每一对捕食关系的平均追逐时间和逃脱率。标准猎物在适配地形、满耐力开局时目标逃脱率可先定为 35–65%；弱势出生或受伤状态自然更低。

### 8.3 生态逆袭参数

生态威胁级按基础击杀经验划分：`≤30 / ≤50 / ≤80 / ≤110 / >110` 分别对应 1–5 级。最终威胁差取生态威胁级差和体型差中的较大值，并限制在 0–4。

```text
破绽条件 = 技能后摇计时 > 0 或 当前耐力 / 最大耐力 ≤ 20%
逆袭额外伤害 = 目标最大生命 × (2% + 威胁差 × 1%)
逆袭有效护甲 = 目标护甲 × 50%
逆袭耐力削减 = 目标最大耐力 × 8%
单个攻击者触发间隔 = 3 秒
力竭进入 / 解除 = 10% / 25% 最大耐力
```

威胁差为 0 时不触发逆袭。技能后摇被一次逆袭消耗，但低耐力破绽会持续到耐力恢复超过 20%。自动校验需要覆盖雪兔对巨象的 4 级威胁差、6% 百分比伤害、部分穿甲、耐力削减、触发冷却和力竭滞回。

### 8.4 草丛隐蔽与伏击参数

```text
有效隐蔽阈值 = 0.58
草丛中蓄势时间 = 0.72 秒
离开草丛后伏击保留 = 0.90 秒
攻击/技能/受击暴露 = 2.20 秒
草丛隐蔽视距系数 = 0.36
近距离揭露 = 4.60 + 观察者体型 × 0.28 米
丢失目标搜索时间 = 2.60 + 追猎者体型 × 0.16 秒
伏击命中留下的破绽 = 1.65 秒
```

体型掩体上限为 `1.00 / 0.90 / 0.68 / 0.24 / 0.00`。只有强度达到 0.58 才能蓄成伏击，因此体型 4–5 无法使用草丛脱锁。血味标记会取消隐蔽并按原规则提高发现距离。

自动校验覆盖：雪兔与巨象在同一草丛的掩体差异、伏击直接触发逆袭、命中后破绽保留，以及追猎者丢失隐蔽目标后进入 `search`。

### 8.5 主场适应与地形反制参数

```text
第一主场：移动 ×1.08，耐力恢复 ×1.14，冲刺消耗 ×0.88
熟悉区域：移动 ×1.045，耐力恢复 ×1.08，冲刺消耗 ×0.94
不适应密林且体型 4–5：移动 ×0.93
不适应高地：体型 4–5 移动 ×0.92，其余移动 ×0.96
地形反制最低适应值 = 0.72
持续移动蓄势时间 = 1.15 秒
离开适应区的蓄势保留 = 0.85 秒（仅用于短暂返回，客场不可触发）
地形反制冷却 = 3.40 秒
地形反制命中留下的破绽 = 1.35 秒
```

第一主场的适应值为 1.0，第二熟悉区域为 0.78，未列出的区域为 0。反制要求攻击者比目标生态威胁更低、攻击者适应当前区域、目标不适应当前区域且双方处于同一区域。地形首击复用逆袭的护甲、百分比生命和耐力削减公式，不再叠加独立伤害倍率。

自动校验覆盖：山羊在高地的移动/耐力收益、客场狮子的移动成本、山羊对狮子的地形逆袭、双方都适应高地时不触发，以及弱势 AI 从草原找到高地并在蓄势后回头反击。

### 8.6 生态借力参数

```text
玩家即时提示/触发半径 = 10.5 米
AI 逃生候选搜索半径 = 14.5 米
第三方与追兵最大触发距离 = 搜索半径 + 3.0 米
第三方最低生命 = 42%
第三方最低耐力 = 24%
第三方最低战力 = 追兵综合战力 ×72%
第三方接战意图 = 4.8 秒
引战者冷却 = 9.0 秒
生态影响归属 = 12.0 秒
第三方击倒助攻经验 = 目标经验 ×45%
```

综合战力只用于候选筛选，由生态威胁级、体型、当前生命和耐力构成，不修改实际伤害。候选还必须具有足够攻击性、领地性、对大体型勇气，或体型不小于追兵。这样雪兔可以把巨象引向健康犀牛，却不能把巨象“强制交给”另一只雪兔。

自动校验覆盖：雪兔识别犀牛而非弱小旁观者、巨象出手后犀牛转火、12 秒助攻归属、9 秒冷却，以及弱势 AI 主动向第三方规划逃生方向。

### 8.7 战术连携与生态掌控参数

```text
可计入路线 = 破绽逆袭 / 草丛伏击 / 主场反制 / 生态借力
单路线首次经验 = 目标当前等级击杀经验 ×10%
单目标战术经验上限 = 目标当前等级击杀经验 ×32%
连携窗口 = 18.0 秒
生态掌控门槛 = 同目标 2 种不同路线
生态掌控恢复 = 6% 最大生命 + 18% 最大耐力
掌控视觉提示 = 3.2 秒
同目标掌控次数 = 1
```

经验按整数四舍五入且最少为 1，但达到 Lv.10 后不再结算经验。路线计奖与掌控记录按“攻击者 + 目标 + 路线”保存于本局内存，死亡重生或进入新世界后清空，不写入存档。目标升级后也不会重置已计奖路线，防止通过养成同一强敌刷取经验。

自动校验覆盖：首次路线经验、同路线防刷、两条路线触发恢复、第三条路线不重复恢复、强打弱无奖励，以及 30 个物种均有可读反制组合。

### 8.8 击杀成长递减与生态适应

```text
捕杀优势档 = 按双方当前有效体型、等级与实时综合战力差连续映射
优势 0 / 1 / 2 / 3 / 4 档经验系数 = 100% / 82% / 68% / 56% / 48%
习性适应经验 = 2 + 主场(1) + 特殊条件(1) + 物种见闻(0～3)
```

击杀递减不改变伤害、尸体食物量、击杀数或胜负。目标当前有效体型和等级先进入基础奖励，再应用捕杀优势系数；以大欺小时继续明显递减，低等级小体型逆袭则获得额外奖励。习性经验与普通首次觅食经验可以同时获得，但两者都按资源实例限次。

### 8.9 生态热点参数

```text
首次出现 = 34 + 1.5 × 关卡 + [0, 12] 秒
后续间隔 = 72 - 1.5 × (关卡 - 1) + [0, 18] 秒
持续时间 = 42 + 0.8 × 关卡 秒
食物点数 = 3 + floor((关卡 - 1) / 3)
可读抵达半径 = 6.5 + 0.18 × 关卡 米
AI 最大信号感知 = 地图宽度 × 72%
```

解锁顺序为落果潮（1 关）、新草繁盛（2 关）、鱼群洄游（3 关）、块根出土（4 关）；已解锁类型优先避免连续重复。每个热点只生成目标生态区中可达的真实 `FoodPatch`，结束后移除；玩家抵达不发放独立经验。

自动校验覆盖：逐关解锁、首次/后续时序、八方向文案、真实食物类型、远距离 AI 感知、HUD 状态及收束清理。

### 8.10 食物链迁徙与围猎参数

```text
活动聚合间隔 = 0.45 秒
猎手硬性拒绝 = 无迁徙猎物 / 可直接吃热点 / 饥饿 < 20
             / 生命 < 46% / 耐力 < 30%
领地型离巢最低饥饿 = 68
猎手响应评分 = 饥饿比例 ×0.45 + 攻击性 ×0.48 + min(迁徙数, 4) ×0.08
确定性响应门槛 = 0.62 + ((actor_id + event_sequence) mod 4) ×0.025
外围埋伏半径 = 热点可读半径 + 3.2 + (actor_id mod 3) ×1.1 米
风险平稳 = 猎手数为 0
风险高危 = 猎手数 ≥3 或 猎手数 ×2 ≥ max(迁徙数, 1)
风险警戒 = 其他存在猎手的情况
弱势避险 = 体型 ≤3、勇气 <0.5、饥饿 <78 且热点为高危
弱势冒险 = 饥饿 ≥78
```

外围方位由 `actor_id + event_sequence` 的确定性角度产生，保证同一世界种子可复现并减少猎手挤在同一点。响应评分只决定是否调查公共信号，不提供具体猎物目标；猎手必须通过正常感知才能从 `hotspot_stalk` 切换到追猎。普通威胁、低血量和热点结束均可中断该状态。

自动校验覆盖：响应与拒绝阈值、领地限制、不同猎手的分散埋伏点、真实迁徙信号计数、猎手状态切换、弱势个体避开高危热点、极饿后重新进入，以及 HUD/世界标签风险同步。

### 8.11 生态踪迹与危险记忆参数


## 12. 阵容生成伪代码

```text
generate_population(level, seed):
    rng = RNG(seed.population)
    selected_biomes = generated_map.biomes
    candidates = filter(level.species_pool, compatible(selected_biomes))

    for retry in 1..MAX_RETRIES:
        species_set = weighted_pick_species(candidates, level.species_type_range)
        quotas = roll_trophic_quotas(level.trophic_quotas, rng)
        roster = fill_individuals(species_set, quotas, level.combatant_count, rng)

        if not has_two_viable_food_chains(roster): continue
        if not every_predator_has_biomass(roster): continue
        if not every_domain_has_sufficient_map_area(roster): continue
        if exceeds_apex_limit(roster): continue
        if not spawn_slots_can_fit(roster): continue

        return roster

    return level.fallback_roster.duplicate_with_seeded_variants(rng)
```

禁止在失败时无限重试。每关提供至少一个经过测试的回退阵容和地图模板，保证加载不会卡死。

## 13. 出生评分参数

```text
player_spawn_score =
    nearest_compatible_food_score × 1.0
  + reachable_cover_score × 1.2
  + escape_route_count_score × 1.4
  + group_proximity_score × species_sociability
  - predator_threat_score × 1.8
  - dead_end_penalty × 2.0

```

硬失败项不参与排序而直接剔除：导航外、碰撞内、无资源可达、无最终区路径、水生水体断连、飞行无落点。

## 14. AI 效用参数约定

所有效用曲线输出 0–1：

- `hunger_need`：饥饿 30 以下近 0，70 后快速升高；
- `health_safety`：生命越低，攻击行为越低、逃跑越高；
- `stamina_safety`：低于技能/逃跑保留值时快速下降；
- `target_weakness`：目标健康 1.0、受伤 1.25、濒危 1.6 后再归一化；
- `size_risk`：每相差一级按画像调整，不用固定禁止；
- `third_party_risk`：附近能在 4 秒内介入的敌对战力；
- `route_confidence`：成功路径 1，不确定 0.5，近期失败 0。

建议状态切换阈值：新行为至少比当前行为高 `0.12`；当前行为已执行超过建议时长后降为 `0.06`。紧急逃跑效用 > `0.82` 时可立即中断非锁定动作。

## 15. 数据校验清单

启动开发构建或导入数据时检查：

- 所有 ID 唯一且本地化键存在；
- 数值不是 NaN、负数或超出合法范围；
- Actor Visual 场景、技能、被动、行为和感知引用存在；
- 食性至少对应一种已注册资源标签；
- 移动域对应至少一个导航策略；
- 技能的命中窗口不长于动作有效时间；
- 冷却非负，耐力成本不超过最大耐力，除非明确允许蓄力；
- 每关个体数、种类范围、营养配额和顶级上限相容；
- 每个 Biome 至少有足够模块、出生槽和资源槽；
- 回退地图与回退阵容存在并已标记测试通过。

数据错误应在编辑器/CI 阶段失败，不应进入玩家运行时后静默使用默认值。

## 16. 首轮平衡测试矩阵

### 16.1 单挑不是最终标准

仍需测试以下组合以发现明显问题：

- 相同体型、满状态、空旷地；
- 捕食者追逐适配猎物；
- 小型物种在专用窄路或草丛；
- 大型物种被 3 个中型围攻；
- 所有技能命中和未命中后的耐力差；
- 最高威胁等级；
- 夜晚、雾、雨和水域优势。

### 16.2 生态统计目标初值

| 指标 | 原型目标区间 |
|---|---|
| 第一关无玩家局长中位数 | 5–8 分钟 |
| 前 30 秒死亡比例 | <10% 个体 |
| 前 60 秒死亡比例 | <25% 个体 |
| 最后两名相遇等待 P90 | <90 秒 |
| 尸体被至少进食一次 | >55% |

## 18. V1.52 水域生存与鱼群参数

