# 《生态轮回》隐私说明

生效版本：1.40.0
更新日期：2026-08-15

《生态轮回》当前版本是一款单机游戏，不要求注册账号，也不包含广告、内购、第三方分析或跨应用追踪 SDK。

## 本地保存的数据

游戏只在设备的应用沙盒中保存：声音与画质设置、教学状态、战役关卡、世界威胁、死亡次数、自由模式选择、物种图鉴、个人最佳成绩和最近十局摘要。这些数据用于继续游戏和展示本地记录，不会由游戏代码上传到开发者服务器。

玩家可在“游戏设置 → 重置游戏”中清除上述进度。卸载原生应用或清除浏览器站点数据也会移除对应平台的本地数据。

## 权限与网络

当前版本不读取相机、麦克风、照片图库、精确或大致位置、联系人、日历、健康数据或广告标识符，也不发送推送通知。

原生 Android/iOS 游戏逻辑不依赖网络。网页版需要浏览器从 GitHub Pages 下载 HTML、JavaScript、WebAssembly、资源包和字体；托管平台或浏览器可能按其自身政策处理标准网络日志，这不由游戏代码收集。

## 儿童与数据出售

游戏不建立用户画像，不出售或共享个人信息，也不通过行为广告获利。由于当前版本不收集可识别个人的数据，因此没有需要提交给开发者删除的云端账户资料。

## 联系与变更

问题可通过本项目 GitHub 仓库的 Issues 提交。若未来加入账号、云存档、排行榜、分析、广告或支付，本说明和商店隐私申报必须在功能发布前更新，并重新取得所需同意。
