# 成长数值与物种攻略

版本：V1.10
适用范围：当前 30 种可玩物种、Lv.1–Lv.8 局内成长

## 1. 设计目标

- 每次升级都能直接感受到变强：生命上限、当前生命、攻击、速度、耐力、护甲与耐力恢复同时提升。
- 不把不同物种练成同一个模板：小型动物靠机动和耐力，捕食者靠攻击，重装与巨兽靠生命和护甲。
- 局内成长只在当局有效，死亡或进入下一个世界后重置，不破坏“随机成为新物种”的公平性。
- 速度成长设置上限：任何物种 Lv.8 速度不超过 Lv.1 的 1.20 倍，防止巨兽升级后无限追击。
- 高收益与高风险绑定：危险物种提供更多经验，且升级后的目标额外增加 14% 经验/级。

## 4. 随机物种的获胜攻略结构

玩家出生后的攻略卡依次回答四个问题：

1. 我的基础生命、攻击、速度、耐力和护甲是多少？
2. 我每级哪些属性成长最快？
3. 我的被动和主动技能应在什么时候使用？
4. 前期如何发育、中期如何利用混战、终局如何处理最后对手？

完整攻略按物种存在 `SpeciesCatalog.VICTORY_GUIDES`。其核心思路如下：

| 物种组 | 前期 | 中期 | 终局 |
|---|---|---|---|
| 雪兔、浣熊、猕猴 | 吃资源、避免换血 | 用地形、树冠或偷食拉开等级 | 保留耐力，引导强敌互斗 |
| 赤狐、猁猈、猎豹 | 只打落单与残血 | 技能命中后立即换位 | 等敌人控制落空后爆发 |
| 狼、鬣狗、狮 | 尽快与同类会合 | 夹击、标记、抢夺尸体 | 失去群体后转为伏击打法 |
| 蛇、鳄鱼、水獭、河马 | 围绕水域与狭口 | 迫使对手在优势地形交战 | 提前占住中央水岸 |
| 熊、豪猪、野牛、陆龟 | 守资源而非追击 | 把技能留给多人近身 | 用生命与护甲迫使敌人先手 |
| 鹿、山羊、斑马、水豚 | 持续迁徙、稳定升级 | 耗尽追猎者耐力 | 控制最后一次冲刺的时机 |
| 大象、犀牛、河马 | 依靠植物维持巨额饱腹消耗 | 用范围技能拆散群猎 | 占据资源中心，优先处理毒和破甲 |
| 猫头鹰、金雕 | 从空中侦察小型落单目标 | 只在落点安全时俯冲 | 保持巡航，等最后的确定机会 |

### 4.1 所有弱物种共通的逆袭路线

面对生态威胁或体型高于自己的目标时，先通过绕行、逃生技能和耐力优势拖延。目标耐力低于 20%，或刚释放主动技能后，敌方血条会显示金色“可逆袭”。此时命中可忽略一半护甲，额外造成目标最大生命 3%–6% 的伤害并削减耐力。一次逆袭后立即撤离，等待 3 秒触发间隔和下一次破绽，不进行连续站桩换血。

### 4.2 草丛主动开战路线

当强敌不愿意先消耗耐力时，体型 1–3 的物种可以转向草丛伏击。进入草丛后停止冲刺，等待状态栏显示“伏击就绪”，再步行接近草丛边缘的强敌。首次普通攻击可直接触发逆袭，不要提前按冲刺或技能。

命中后强敌会保留短暂破绽，可以引导附近捕食者接手，自己立即退回另一处掩体。如果身上带有血味标记，或追猎者已经贴到草丛边缘，应放弃蓄势并继续转移。

### 4.3 主场环境反制路线

出生简报和自由模式物种预览会显示每种动物的第一主场与熟悉区域。第一主场提供最明显的移动和耐力效率，熟悉区域收益较低。进入适应区域后持续移动约 1.15 秒，状态栏会显示对应的“密林周旋 / 旷野游斗 / 浅滩牵制 / 岩径反制就绪”。

把不适应该区域的强敌引进同一区域，再用普通攻击命中即可直接发动一次逆袭；双方都适应该区域时不会触发。例如山羊可以把草原雄狮引入岩丘高地后反打，水獭可以在湿地牵制纯陆地强敌，但不能依靠湿地补偿对付同样适应水域的鳄鱼。

地形逆袭后有 3.4 秒冷却并需要重新移动蓄势。正确节奏是“换区 → 周旋 → 首击 → 利用短破绽或撤离”，而不是站在主场持续换血。最终收束圈关闭该蓄势，终局仍要依靠已经建立的等级、耐力和技能优势完成决战。

### 4.4 生态借力路线

强敌主动追击时，观察状态栏和敌方血条的紫色提示。系统会给出附近真正有能力介入的第三方，例如健康犀牛、领地河马、棕熊或另一只顶级捕食者。沿提示目标方向移动，让追兵跟入其附近，再诱使追兵命中一次；第三方会把追兵视为当前冲突目标并接战。

引战成功后有三种选择：生命较低时立即脱离；自身还有耐力时绕到侧面等待强敌破绽；目标濒危时准备补刀。即使不完成最后一击，只要追兵在 12 秒影响窗口内被第三方击倒，也能获得 45% 经验和生态助攻。

生态借力不是免费召唤友军。候选必须健康且足够强，触发需要承受一次诱导攻击，第三方结束战斗后仍可能把弱者视为猎物。正确节奏是“确认紫色对象 → 保留逃生耐力 → 引导追兵出手 → 借混战换位”，不要站在两只强兽中间等待结果。

### 4.5 战术连携与生态掌控

对同一只强敌首次完成任意反制路线会获得其击杀经验的 10%。18 秒内再完成另一种路线，例如“草丛伏击 → 生态借力”“主场反制 → 耐力破绽”，即可触发生态掌控，恢复 6% 最大生命和 18% 最大耐力。每个目标的战术经验最多为其价值的 32%，同路线不重复计奖，同一目标只触发一次掌控。

每个物种出生简报和自由模式预览都会显示专属“反制组合”。恢复的正确用途是脱离包围、补足一次冲刺或重新争取资源，不是留在强敌面前继续站桩。生态掌控不提供攻击、护甲或速度加成，最终胜利仍依赖等级、食物、路线和时机。

## 5. 平衡守则

- 升级不降低技能冷却、不增加攻击距离，防止高级爆发者失去反制窗口。
- 高生命物种的速度成长一定低于小型物种；高速物种的护甲成长一定低于重装物种。
- 自动校验要求每种物种 Lv.8 的生命、攻击、速度和耐力都高于 Lv.1，同时不超过首发版成长上限。
- 逆袭只在攻击更强且处于破绽的目标时生效，不按玩家身份提供隐藏加成，AI 同样使用该规则。
- 战术经验只奖励不同路线的首次成功；AI 与玩家共享 18 秒连携、32% 经验上限和同目标一次掌控规则。
- 后续平衡不只看面板，还需每关运行自动生态模拟，统计首杀率、平均等级、胜率、饥饿死亡率和单局时长。
