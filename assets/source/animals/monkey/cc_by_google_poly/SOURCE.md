# Macaque reference provenance

- Title: `monkey`
- Creator: Poly by Google
- Source: https://poly.pizza/m/0yRz2AkLuuo
- License: Creative Commons Attribution 3.0 Unported
- Published: 2017-09-25
- Source listing: approximately 1.4k triangles / 1.45k vertices, OBJ/GLTF
- Access checked: 2026-08-16

The production GLBs are generated by `tools/blender/build_cinematic_monkey.py`.
They retain the project's 22-bone runtime contract while rebuilding a macaque's
short steep torso, long grasping forelimbs, bent hind limbs, bare face, rounded
ears, articulated hands and feet, and a continuously skinned curved balance
tail. The linked model is used only to cross-check silhouette and proportion.
