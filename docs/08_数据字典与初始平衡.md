# 数据字典与初始平衡

## 1. 使用说明

本文数值用于 Godot 原型起步和自动测试，不代表最终发行平衡。所有值均应存入自定义 Resource，并由数据校验工具检查；脚本只实现公式，不为单一物种硬编码例外。

约定：

- 距离单位为米；
- 时间单位为秒；
- 角度在数据层使用度，运行时按 API 需要转换；
- 百分比在数据中使用 0–1；
- 体型级 1–5；
- 所有 ID 使用稳定英文 `StringName`，显示名独立本地化。

## 8. 耐力和平衡公式

### 8.1 恢复

```text
实际恢复 = 基础恢复
         × 行动系数（静止1.0 / 步行0.7 / 其他0）
         × 饥饿系数（正常1.0 / 饥饿0.85 / 极饿0.65）
         × 天气系数
```

### 8.2 追逃基准

每个物种至少通过以下之一脱战：

- 速度优势能在 6–10 秒内拉开攻击距离；
- 耐力效率能让追击者先力竭；
- 技能制造至少 1.5 秒安全窗口；
- 专用地形通路使天敌不可达；
- 防御能拖到第三方介入，但不能无限无损耗。

自动测试记录每一对捕食关系的平均追逐时间和逃脱率。标准猎物在适配地形、满耐力开局时目标逃脱率可先定为 35–65%；弱势出生或受伤状态自然更低。

### 8.3 生态逆袭参数

生态威胁级按基础击杀经验划分：`≤30 / ≤50 / ≤80 / ≤110 / >110` 分别对应 1–5 级。最终威胁差取生态威胁级差和体型差中的较大值，并限制在 0–4。

```text
破绽条件 = 技能后摇计时 > 0 或 当前耐力 / 最大耐力 ≤ 20%
逆袭额外伤害 = 目标最大生命 × (2% + 威胁差 × 1%)
逆袭有效护甲 = 目标护甲 × 50%
逆袭耐力削减 = 目标最大耐力 × 8%
单个攻击者触发间隔 = 3 秒
力竭进入 / 解除 = 10% / 25% 最大耐力
```

威胁差为 0 时不触发逆袭。技能后摇被一次逆袭消耗，但低耐力破绽会持续到耐力恢复超过 20%。自动校验需要覆盖雪兔对巨象的 4 级威胁差、6% 百分比伤害、部分穿甲、耐力削减、触发冷却和力竭滞回。

### 8.4 草丛隐蔽与伏击参数

```text
有效隐蔽阈值 = 0.58
草丛中蓄势时间 = 0.72 秒
离开草丛后伏击保留 = 0.90 秒
攻击/技能/受击暴露 = 2.20 秒
草丛隐蔽视距系数 = 0.36
近距离揭露 = 4.60 + 观察者体型 × 0.28 米
丢失目标搜索时间 = 2.60 + 追猎者体型 × 0.16 秒
伏击命中留下的破绽 = 1.65 秒
```

体型掩体上限为 `1.00 / 0.90 / 0.68 / 0.24 / 0.00`。只有强度达到 0.58 才能蓄成伏击，因此体型 4–5 无法使用草丛脱锁。血味标记会取消隐蔽并按原规则提高发现距离。

自动校验覆盖：雪兔与巨象在同一草丛的掩体差异、伏击直接触发逆袭、命中后破绽保留，以及追猎者丢失隐蔽目标后进入 `search`。

## 12. 阵容生成伪代码

```text
generate_population(level, seed):
    rng = RNG(seed.population)
    selected_biomes = generated_map.biomes
    candidates = filter(level.species_pool, compatible(selected_biomes))

    for retry in 1..MAX_RETRIES:
        species_set = weighted_pick_species(candidates, level.species_type_range)
        quotas = roll_trophic_quotas(level.trophic_quotas, rng)
        roster = fill_individuals(species_set, quotas, level.combatant_count, rng)

        if not has_two_viable_food_chains(roster): continue
        if not every_predator_has_biomass(roster): continue
        if not every_domain_has_sufficient_map_area(roster): continue
        if exceeds_apex_limit(roster): continue
        if not spawn_slots_can_fit(roster): continue

        return roster

    return level.fallback_roster.duplicate_with_seeded_variants(rng)
```

禁止在失败时无限重试。每关提供至少一个经过测试的回退阵容和地图模板，保证加载不会卡死。

## 13. 出生评分参数

```text
player_spawn_score =
    nearest_compatible_food_score × 1.0
  + reachable_cover_score × 1.2
  + escape_route_count_score × 1.4
  + group_proximity_score × species_sociability
  - predator_threat_score × 1.8
  - dead_end_penalty × 2.0
  - domain_mismatch_penalty × 10.0
```

硬失败项不参与排序而直接剔除：导航外、碰撞内、无资源可达、无最终区路径、水生水体断连、飞行无落点。

## 14. AI 效用参数约定

所有效用曲线输出 0–1：

- `hunger_need`：饥饿 30 以下近 0，70 后快速升高；
- `health_safety`：生命越低，攻击行为越低、逃跑越高；
- `stamina_safety`：低于技能/逃跑保留值时快速下降；
- `target_weakness`：目标健康 1.0、受伤 1.25、濒危 1.6 后再归一化；
- `size_risk`：每相差一级按画像调整，不用固定禁止；
- `third_party_risk`：附近能在 4 秒内介入的敌对战力；
- `route_confidence`：成功路径 1，不确定 0.5，近期失败 0。

建议状态切换阈值：新行为至少比当前行为高 `0.12`；当前行为已执行超过建议时长后降为 `0.06`。紧急逃跑效用 > `0.82` 时可立即中断非锁定动作。

## 15. 数据校验清单

启动开发构建或导入数据时检查：

- 所有 ID 唯一且本地化键存在；
- 数值不是 NaN、负数或超出合法范围；
- Actor Visual 场景、技能、被动、行为和感知引用存在；
- 食性至少对应一种已注册资源标签；
- 移动域对应至少一个导航策略；
- 技能的命中窗口不长于动作有效时间；
- 冷却非负，耐力成本不超过最大耐力，除非明确允许蓄力；
- 每关个体数、种类范围、营养配额和顶级上限相容；
- 每个 Biome 至少有足够模块、出生槽和资源槽；
- 回退地图与回退阵容存在并已标记测试通过。

数据错误应在编辑器/CI 阶段失败，不应进入玩家运行时后静默使用默认值。

## 16. 首轮平衡测试矩阵

### 16.1 单挑不是最终标准

仍需测试以下组合以发现明显问题：

- 相同体型、满状态、空旷地；
- 捕食者追逐适配猎物；
- 小型物种在专用窄路或草丛；
- 大型物种被 3 个中型围攻；
- 所有技能命中和未命中后的耐力差；
- 最高威胁等级；
- 夜晚、雾、雨和水域优势。

### 16.2 生态统计目标初值

| 指标 | 原型目标区间 |
|---|---|
| 第一关无玩家局长中位数 | 5–8 分钟 |
| 前 30 秒死亡比例 | <10% 个体 |
| 前 60 秒死亡比例 | <25% 个体 |
| 最后两名相遇等待 P90 | <90 秒 |
| 尸体被至少进食一次 | >55% |
| 非玩家造成击杀的测试局 | >60% |
