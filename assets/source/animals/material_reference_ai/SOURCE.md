# AI 动物表面方向板

生成日期：2026-08-23

用途：为《生态轮回》30 种动物的独立实时 PBR 表面图集提供毛发、羽毛、鳞片、甲壳和无毛皮肤的颜色与微结构来源。方向板不会直接作为整张共享贴图进入游戏；`tools/build_individual_species_surface_maps.gd` 会按固定物种顺序裁切，并逐种生成独立的 512×512 Hero 与 128×128 Mobile Albedo、Normal、Roughness 图集。

生成工具：Codex 内置 ImageGen。

共同约束：正交微距表面摄影、柔和中性棚拍、五个分隔材质区、无完整动物、无身体部位、无文字、无标志、无水印、避免纯色和塑料质感。

| 文件 | 从左至右物种 |
|---|---|
| `small_mammals.png` | 雪兔、赤狐、浣熊、豪猪、水豚 |
| `predators.png` | 灰狼、雄狮、猛虎、猎豹、猞猁 |
| `ungulates.png` | 林鹿、野牛、斑马、驼鹿、山羊 |
| `coarse_mammals.png` | 棕熊、野猪、水獭、狼獾、鬣狗 |
| `primates_and_hide.png` | 猕猴、银背猩猩、非洲巨象、犀牛、河马 |
| `feather_scale_shell.png` | 雕鸮、金雕、青环蛇、沼泽鳄、陆龟 |

生成提示按每张表的物种顺序明确指定对应成年动物的毛色、纤维长度、花纹、皮肤褶皱、羽片、鳞片或甲壳结构，并要求五个区域保持一致的尺度与光照。最终游戏图集由项目生成器确定性地产生，便于重建、审计和跨端压缩。
