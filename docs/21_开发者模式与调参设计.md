# 《生态轮回》开发者模式与运行时调参设计

版本：V1.76

## 1. 目标与边界

开发者模式用于快速验证手感、成长速度、资源密度、终局节奏与 AI 智能，不是面向正式战绩的作弊菜单。设计遵守四条边界：

1. 玩家和 AI 继续共用 `EcoActor` 与同一套动物属性乘数，不能只强化玩家；
2. 调试局从启用开发者模式的那一刻起锁定为“非正式”，胜负、死亡和发现不会写入战役进度、世界威胁、图鉴战绩或最近轮回；
3. 自动烟测、批量生态模拟和性能基线始终忽略本机开发参数，保持固定种子结果可比较；
4. 所有输入先经过白名单、NaN/Inf 检查、上下限和步长清洗，未知 JSON 字段不会进入运行时。

## 2. 进入流程

首页或暂停菜单进入“游戏设置”，点击“开发者模式”打开横屏实时平衡台。首次进入时参数不可编辑，必须明确打开“启用开发者模式”。关闭开关会让即时参数恢复正式默认值，但已经标记为调试局的当前对局不会重新获得正式成绩资格。

界面采用固定标题/底部操作区与中间滚动列表，支持 Web、Android、iOS 与桌面。每个数值都有减号、可输入数字框和加号；触摸目标不小于 52 逻辑像素。参数标明“即时生效”或“下局生效”。

## 3. 参数目录

### 3.1 动物属性（即时）

| 参数 | 默认 | 范围 | 作用 |
|---|---:|---:|---|
| 生命上限 | 1.00× | 0.25–5.00 | 全体动物最大生命；调整时保持当前生命比例 |
| 攻击伤害 | 1.00× | 0.25–5.00 | 普通攻击与主动技能的共同攻击基础 |
| 护甲强度 | 1.00× | 0–4.00 | 成长护甲与随机护甲进化的总乘数 |
| 动物体型 | 1.00× | 0.50–2.00 | 模型、有效体型、碰撞、涉水线和战斗体型判断 |
| 移动速度 | 1.00× | 0.50–2.00 | 玩家与 AI 行走、追击和逃跑速度 |
| 耐力上限 | 1.00× | 0.25–4.00 | 最大耐力；调整时保持当前耐力比例 |
| 耐力恢复 | 1.00× | 0.25–4.00 | 普通恢复与成长恢复的共同乘数 |
| 饥饿增长 | 1.00× | 0–4.00 | 0 会关闭自然饥饿增长 |
| 技能耐力消耗 | 1.00× | 0–3.00 | 0 可用于无消耗技能测试 |
| 技能冷却时间 | 1.00× | 0.20–3.00 | 越小恢复越快，不改变技能命中逻辑 |

### 3.3 世界规则

| 参数 | 默认 | 范围 | 生效 | 作用 |
|---|---:|---:|---|---|
| 动物数量 | 1.00× | 0.25–1.50 | 下局 | 按关卡 10–100 个缩放，并限制为 2–150 |

| 安全圈收缩速度 | 1.00× | 0.25–4.00 | 即时 | 不改变各关最终安全圈半径 |

### 3.4 AI 智能（即时）

| 参数 | 默认 | 范围 | 作用 |
|---|---:|---:|---|
| AI 思考速度 | 1.00× | 0.25–3.00 | 缩放错峰感知与重新决策间隔 |
| AI 感知范围 | 1.00× | 0.25–3.00 | 发现动物、资源和局部危险的距离 |
| AI 追踪记忆 | 1.00× | 0.25–3.00 | 失去视野后的搜索时间 |
| AI 协作范围 | 1.00× | 0.25–3.00 | 同类分享猎物、危险与资源信息的强度 |

开发参数叠加在简单/冒险/困难难度之后。即使将 AI 参数调高，AI 仍只能使用现有局部感知、踪迹与同类情报，不会获得玩家专属仇恨或全图坐标。

## 4. 生效与持久化

- `scripts/developer_tuning.gd` 是参数 ID、分类、默认值、范围、步长和生效标签的唯一来源；
- `main.gd` 保存开关与白名单参数，并向 `EcoActor`、`EcoWorld` 和 UI 提供当前有效值；
- `SAVE_VERSION = 7`，存档新增 `[developer] enabled/schema/values`，战役重置会保留开发参数；
- 关闭开发者模式或运行自动化时，读取函数返回正式默认值，非默认配置仍保留供下次调试；
- “复制 JSON”输出带 schema 的完整白名单；“导入剪贴板”只有在 JSON 结构合法时才替换配置。

## 5. 验收标准

1. 旧存档迁移后开发者模式默认关闭，所有参数为 1.00×/60 秒；
2. 28 个参数均能经过范围清洗、保存、退出重进和 JSON 往返；
3. 同一物种的玩家与 AI 在相同等级下得到相同开发属性；
4. 即时调整生命/耐力时保留比例，体型同步更新模型与碰撞；
5. 调试局胜负不改变战役、威胁、图鉴记录和最近轮回；
6. 自动模拟和性能基线不读取本机开发参数；
7. 1280×720 手机横屏中四类选择、滚动数值行和底部操作完整可触摸；
8. 默认参数下的第 1/10 关生态结果与 V1.75 平衡保持可比较。

## 6. 后续扩展

当前版本优先解决“全局快速调平衡”。后续可以在同一白名单架构上增加：单物种覆盖、固定天气/昼夜、指定生态事件、实时曲线图、参数预设槽和一键生成平衡报告。它们必须继续使用非正式调试局隔离，不能直接修改 `SpeciesCatalog.DATA` 或覆盖正式默认值。
