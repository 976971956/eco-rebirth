# Lv.10 实时体型成长、局内适应与物种攻略

版本：V1.57
适用范围：30 种可玩物种、10 个关卡、Web / Android / iOS / Desktop

## 1. 本版解决的问题

旧成长只对初始面板做复利。雪兔即使升级，战斗、AI、掩体和逆袭仍按“初始小型物种”判断；巨兽又会靠高基础数值和复利扩大优势。V1.57 改为一条统一的实时体型曲线：

- 最高等级由 Lv.8 提高到 Lv.10；
- 升级提高有效体型，模型、碰撞、生命、攻击、护甲、速度、耐力、恢复和食量同步变化；
- 同一实时体型下，生命和攻击的物种差控制在约 16% 内；
- 物种差异主要由速度、攻击节奏、主动技能、被动、食性、水性、栖息地和群体行为形成；
- 弱物种能通过营养食物、战术经验和主场路线成长，不必只逃跑；
- 大体型仍有更高终局上限，但也承担更高食量、可见度、转向和冲刺成本。

所有成长和适应只保留在当前世界，不写入永久属性存档。

## 2. 实时体型曲线

设等级进度：

```text
成长进度 P = ((等级 - 1) / 9)^0.85
实时体型 S = 初始体型 + (满级体型 - 初始体型) × P
```

| 初始体型组 | 实时体型 Lv.1→10 | 最大视觉倍率 | 设计含义 |
|---:|---:|---:|---|
| 1 微型 | 1.0→3.2 | 1.75× | 雪兔等可以真正成长为中型个体 |
| 2 小型 | 1.8→3.8 | 1.55× | 小型猎手和灵活动物获得明显体量成长 |
| 3 中型 | 2.7→4.6 | 1.40× | 中型动物进入大型竞争区间 |
| 4 大型 | 3.8→5.4 | 1.28× | 保留高上限，同时控制屏幕占用 |
| 5 巨型 | 4.9→6.4 | 1.18× | 天生强势，但视觉增长更克制 |

模型只使用受控视觉倍率；战斗、碰撞、攻击距离修正、掩体、水线、AI 威胁和经验结算读取完整实时体型。这样既能看出变大，又不会让移动端画面被模型完全遮住。

## 3. 核心属性公式

```text
基础生命 = (28 + 28 × S^1.65) × 生态原型生命修正
基础攻击 = (3 + 4 × S^1.50) × 生态原型攻击修正
基础护甲 = 8 × max(S - 1, 0) + 原型护甲修正
```

六类生态原型的生命/攻击修正只在 0.94～1.08 之间。陆龟等明确以护甲为身份的物种可保留专项护甲，但不会同时获得异常生命和攻击。

速度最高增长 18%，巨兽最高增长 9%；耐力最高增长 36%；恢复最高增长 25%。升级补足新增生命/耐力池，另恢复 12% 新生命上限与 22% 新耐力上限。大量营养食物已成为主要续航来源，因此升级不再提供 30%/42% 的过高战斗治疗。

成长后的代价：

- 饥饿增长会随等级和体型倍率提高；
- 冲刺消耗直接读取实时体型；
- 大型身体转向更慢，也更难利用普通草丛；
- 安全涉水深度会随身体高度小幅增加，但水性和屏息仍由物种决定；
- 尸体的可食量、保留时间、视觉大小和习性判定读取死亡时的实时体型；
- 长大的雪兔能获得更强正面能力，但会逐步失去微型动物的隐蔽优势。

## 4. 升级门槛与经验来源

基础门槛为：

```text
Lv.1→2   45
Lv.2→3   90
Lv.3→4   150
Lv.4→5   225
Lv.5→6   315
Lv.6→7   420
Lv.7→8   540
Lv.8→9   675
Lv.9→10  825

实际门槛 = 基础门槛 × clamp(0.82 + 当前实时体型 × 0.12, 0.90, 1.58)
```

小型动物前期升级较快；身体越大，维持下一次成长需要的经验越多。

经验来源：

- 普通营养食物首次发现：3～5，偏好食物 +2，第一主场 +1；
- 丰饶营养食物：6～9，再叠加偏好和主场；
- 稀有营养食物：15～25，再叠加偏好和主场；
- 同一动物等待同一食物再生不会重复获得经验；
- 击杀经验按被击杀者当前实时体型和等级计算；
- 强者击杀明显弱者仍按 82% / 68% / 56% / 48% 递减；
- 弱者击倒强者按实时威胁差获得每档 8% 的额外奖励；
- 破绽、伏击、主场反制、生态借力的首次战术经验仍为目标价值 10%，单目标上限 32%。

## 5. Lv.3 / Lv.6 / Lv.9 局内适应

每到一个里程碑，玩家暂停世界并三选一；AI 使用生命、耐力、饥饿、性格、食性和当前战况选择同样的路线。每条路线可重复选择到 3 级，也可混合构筑。

| 路线 | 每级效果 | 不能替代的风险 |
|---|---|---|
| 生境适应 | 主场移动 +3%、主场恢复 +7%、主场冲刺消耗 -6%，掩体准备更快，涉水路线略稳 | 客场不生效；不会提供常驻高伤害 |
| 战斗技艺 | 主动技能消耗与冷却各 -6%，技能后摇略缩短，破绽战术收益更稳定 | 仍需命中；不能删除技能后摇和耐力风险 |
| 生态关系 | 首次食物经验 +12%，营养和习性恢复 +6% | 同一资源仍只结算一次经验，不能原地刷级 |

三十种动物都有独立显示名，例如雪兔为“草影 / 折返 / 多点觅食”，灰狼为“驱赶者 / 截击扑杀 / 分食秩序”。完整路线表见[可玩性玩法方案](18_可玩性玩法方案.md)。

## 7. 弱物种的完整逆袭循环

1. 在安全区域寻找未探索营养食物，优先偏好食物、主场和稀有紫色食物点；
2. 用速度、水性、草丛或生态习性避免无收益换血；
3. 到 Lv.3 后根据本局地图选择生境、战斗或生态路线；
4. 判断双方当前实时体型，而不是只看物种名字；
5. 用低耐力、技能后摇、草丛伏击、主场反制或第三方引战制造破绽；
6. 完成两种不同战术触发生态掌控，恢复 6% 生命和 18% 耐力；
7. 成长后的身体可以参与正面战斗，但必须承担更高食量、可见度和移动成本。

雪兔并不是直接获得“对巨象伤害加成”。它先靠草地觅食、月影折跃和草丛路线成长；当实际体型接近中型动物时，系统会自然降低其弱者补偿。面对仍明显更大的目标，才继续获得破绽逆袭和高价值经验。

## 8. AI 使用同一规则

AI 不读取玩家身份，也没有隐藏属性。它会：

- 在小体型或低等级时主动比较未探索营养食物的经验、距离、水深和竞争风险；
- 使用当前体型、当前战力、双方生命/耐力、群体支援和主场差评估猎物；
- 长大后降低草丛价值，提高食量、转向和冲刺成本；
- 在 Lv.3/6/9 根据当前生命、饥饿、攻击性、食性、群猎和领地性自动选择适应；
- 对同一失败路线保留短期记忆，连续卡路会换目标或方向；
- 只有肉食和合法杂食动物主动捕猎，食草动物仍以迁徙、反击和生态借力为主。

## 9. 自动验收

发布前必须同时通过：

- 30 种物种 Lv.1→10 确定性属性、模型倍率与实时碰撞；
- 同体型生命/攻击差不超过 16%；
- 普通/丰饶/稀有食物经验与同源防刷；
- AI 营养觅食、主动捕猎、危险绕行、连续卡路改道；
- 实时威胁、击杀经验、战术经验和生态掌控；
- Lv.3/6/9 玩家选择与 AI 对称选择；
- 第 1/10 关最大体型通行连通率不低于 97%；
- 第 1/5/10 关性能门禁和 Web / iOS 构建。

数据实现位于 `scripts/species_catalog.gd`、`scripts/eco_actor.gd`、`scripts/food_patch.gd` 与 `scripts/eco_world.gd`；自动报告由 `tools/report_growth_balance.gd` 生成。
