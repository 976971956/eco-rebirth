# Goat reference provenance

- Title: `Goat`
- Creator: Poly by Google
- Source: https://poly.pizza/m/d7dImmjtF8E
- License: Creative Commons Attribution 3.0 Unported
- Published: 2017-10-23
- Source listing: 958 triangles / approximately 1.6k vertices, OBJ/GLTF
- Access checked: 2026-08-16

The production GLBs are generated by
`tools/blender/build_cinematic_goat.py`. They retain the project's 22-bone
runtime contract while rebuilding an adult mountain goat's compact trunk,
sloped neck, swept segmented horns, beard, narrow lower legs and split hooves.
The linked model is used only to cross-check silhouette and proportion.
