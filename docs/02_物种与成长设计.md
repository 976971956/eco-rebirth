# 物种与成长设计

## 1. 物种设计目标

每个物种不是一组不同数值，而是一种不同的生存问题。设计一个物种时必须同时回答：

1. 它吃什么，如何稳定获得食物？
2. 它怕谁，如何脱离天敌？
3. 它擅长击杀谁，靠爆发、消耗、群体还是地形？
4. 它在什么地形获得优势？
5. 它的主动技能如何改变战局，而非只增加伤害？
6. 玩家在 10 秒内如何看懂以上信息？

## 2. 物种数据构成

每种生物由四层数据组合：

- **基础属性**：生命、攻击、速度、耐力、护甲、体型；
- **生态标签**：食性、栖息地、活动时段、移动域、群居性；
- **行为画像**：攻击性、胆量、贪食、耐心、好奇、领地性；
- **能力套件**：基础攻击、一个主动技能、一个被动特征。

美术场景和数值数据分离。同一个物种数据可使用不同外观变体；同一个技能模板可由不同物种配置不同参数。

### 2.1 V2 物种美术契约

V1.4 使用 AI 方向图约束轮廓、配色和材质，再由 `low_poly_factory.gd` 与 `eco_actor.gd` 生成实际可运行动物。所有 30 种物种遵守以下规则：

- 主体使用连续低多边形曲面，逐面法线和轻微色差塑造体积，减少积木式圆球拼接感；
- 先保证远距离剪影可识别，再添加条纹、甲片、角、耳、尾、眼部高光等身份特征；
- 四足动物共享行走骨架节奏，但腿长、步幅、重心和摆尾幅度按体型与物种组区分；
- 眼睛至少包含眼窝、虹膜、瞳孔和高光，捕食者、草食者与水生物种使用不同朝向与颜色；
- 运行时材质以粗糙非金属表面为主，禁止依赖桌面端专用渲染特性；
- 单个物种的造型节点、技能特效与生命条必须保持独立，不得因视觉升级改变攻击碰撞和移动半径。

AI 生成的栅格图只作为美术方向和地表素材，不冒充已经绑定骨骼的 3D 模型。未来替换为正式 GLB 时，仍需遵守现有碰撞、脚底高度、朝向、动画状态与三端性能契约。

## 3. 移动域

| 移动域 | 实现与限制 | 优势 |
|---|---|---|
| 陆地 | 地面导航层；受坡度、窄路和水深限制 | 掩体与路线最多 |
| 两栖 | 地面与浅水导航层切换 | 跨河、逃入水域 |
| 水生 | 水域专用导航体积，离水受伤或无法行动 | 水中速度与伏击 |
| 飞行 | 限高的 3D 航路/高度带；需落点进食 | 跨越障碍、俯冲 |
| 穴居 | 陆地导航 + 指定洞口链接 | 隐蔽、捷径 |

首版飞行不是无限自由飞行。飞行物种在“巡航”和“低空战斗”两种高度带间切换，技能控制俯冲；这样可保持镜头、命中和导航稳定。

### 3.1 当前四区域环境适应

30 种物种均通过 `BIOME_PREFERENCES` 声明有序的适应区域。第一项是主场，第二项是熟悉区域；该顺序同时用于出生、移动效率、耐力效率、物种简报和地形反制，不再只是生成权重。

| 区域 | 主要路线 | 代表弱势使用者 | 典型被反制者 |
|---|---|---|---|
| 古木林地 | 密林周旋、草丛和短转向 | 雪兔、赤狐、青环蛇、猕猴 | 不适应密林的大型追击者 |
| 日照草原 | 长直线、耐力换位 | 林鹿、斑马、猎豹 | 失去开阔地效率的重装目标 |
| 浅水湿地 | 浅滩切线、水陆换区 | 水豚、水獭、陆龟 | 不具两栖适应的陆地强敌 |
| 岩丘高地 | 岩径转向、短距高地路线 | 山羊、猞猁、狼獾 | 不适应高地的大型/巨型追兵 |

主场不会直接提高攻击面板。弱物种必须持续移动完成蓄势，并把不适应该区域的强敌一起带入同一区域，才能用普通攻击触发一次地形逆袭。这样环境优势来自路线选择，而不是出生在正确象限后的常驻伤害光环。

## 4. 食性标签

- `herbivore`：植物、果实、水草；
- `carnivore_fresh`：新鲜尸体和活体猎物；
- `scavenger`：腐败尸体收益高；
- `omnivore`：多类食物可用但效率中等；
- `piscivore`：环境鱼群或小型水生单位；
- `venom_resistant`：可食用有毒目标；
- `cannibal_when_starving`：极端饥饿时允许攻击同种。

食性是多标签组合，不用单一枚举限制后续扩展。

## 5. 行为画像

画像参数取 0–1，由 AI 效用评分读取：

| 参数 | 高值表现 |
|---|---|
| aggression | 更早主动攻击，容忍较高风险 |
| courage | 更晚逃跑，更敢接近大体型 |
| greed | 更重视高价值尸体和残血目标 |
| patience | 愿意伏击、观察、等待冲突结束 |
| sociability | 寻找同类并保持群体距离 |
| territoriality | 驱赶进入领地的个体 |
| curiosity | 主动调查声音和未知气味 |

画像只改变决策偏好，不直接作弊式获取玩家位置。

## 6. 物种原型角色

为了控制制作量，先用可复用原型覆盖多数物种：

1. **敏捷草食者**：低血高速度，技能位移，靠路线和耐力管理。
2. **群体追猎者**：单体一般，同类协作包夹和轮换追击。
3. **伏击者**：正面弱，藏匿后首击强，偏好草丛、树冠或浅水。
4. **重装反击者**：速度慢、稳定高，技能防御或范围击退。
5. **机会主义者**：感知强、擅长补刀和抢尸，不愿公平战斗。
6. **顶级捕食者**：少量出现，正面强但消耗高、转向慢、目标明显。
7. **控制型生物**：毒、减速、恐惧或地形封锁，靠时间取胜。
8. **领域专家**：在水、空中、洞穴、雪地等特定环境明显占优。

## 7. 首批物种设计

### 7.1 兔子

- 原型：敏捷草食者；体型 1；陆地；
- 优势：速度快、目标小、草丛中感知距离降低；
- 劣势：生命低，正面攻击弱；
- 被动“警觉”：附近出现锁定自己的捕食者时，短暂获得方向提示；
- 主动“急转跃迁”：向移动方向跳跃，短时间提高转向并穿过低矮灌木；
- 胜利路线：隐藏、诱导捕食者互斗、最后收割力竭目标。

### 7.2 狐狸

- 原型：机会主义者；体型 2；杂食；
- 优势：嗅觉强，对残血目标伤害提高；
- 劣势：正面耐力和稳定值一般；
- 被动“机会嗅觉”：更远发现尸体和生命低于 30% 的目标留下的痕迹；
- 主动“佯攻”：快速突进撕咬，若未命中则返还部分耐力；
- 胜利路线：跟随混战、补刀、抢食后脱离。

### 7.3 狼

- 原型：群体追猎者；体型 3；肉食；
- 优势：附近同类攻击同一目标时获得耐力效率和包夹评分；
- 劣势：落单时数值只属中等；
- 被动“群猎”：同群成员共享最近猎物位置，但有短延迟；
- 主动“扑咬”：短距离扑向目标，命中小体型可短暂压制；
- 胜利路线：维持群体至中盘，再处理可能成为对手的同类。

### 7.4 鹿

- 原型：大型敏捷草食者；体型 3；
- 优势：持续跑动效率高，开阔地速度快；
- 劣势：转向半径大，洞穴和密林不利；
- 被动“顺势奔跑”：连续直线移动逐步降低冲刺消耗；
- 主动“蹬踢”：快速后踢并强力击退追击者；
- 胜利路线：拖垮追击者，把天敌带入大型动物领地。

### 7.5 蛇

- 原型：控制型伏击者；体型 2；
- 优势：草丛隐蔽，毒伤能迫使强敌撤退；
- 劣势：追击和正面承伤弱；
- 被动“冷伏”：静止一定时间后降低被视觉发现距离；
- 主动“毒牙”：短前摇咬击，造成低即时伤害和持续毒素；
- 胜利路线：控制要道、毒伤收割、让中毒目标吸引其他猎手。

### 7.6 熊

- 原型：重装反击者；体型 4；杂食；
- 优势：生命和稳定值高，食物选择多；
- 劣势：转向慢、持续追击差、目标明显；
- 被动“怒意”：受到攻击后短时间提高稳定与伤害，但不叠加；
- 主动“重击”：范围拍击，造成高冲击和击退；
- 胜利路线：占据尸体热点，逼迫其他个体进入自己的近战范围。

### 7.7 鹰

- 原型：空中机会主义者；体型 2；
- 优势：跨地形、视野远、擅长攻击小型和残血目标；
- 劣势：落地进食时脆弱，俯冲失误有长后摇；
- 被动“高空视野”：巡航时视距提高，但无法普通攻击；
- 主动“俯冲”：标记地面落点后高速下降攻击，随后进入低空状态；
- 胜利路线：持续寻找孤立小型目标，谨慎选择落地进食时机。

### 7.8 乌龟

- 原型：防御领域专家；体型 2；两栖；
- 优势：护甲高，水边路线多；
- 劣势：陆地慢，难以主动结束战斗；
- 被动“甲壳”：背后和侧后方受到的伤害降低；
- 主动“缩壳”：停止移动并大幅减伤与抗击退，缓慢恢复耐力；
- 胜利路线：利用水陆边界和缩壳等待敌人被第三方攻击。

### 7.9 鳄鱼

- 原型：水域伏击者；体型 4；两栖；
- 优势：浅水隐蔽、首击强、能拖拽小体型；
- 劣势：离水后持续机动差；
- 被动“静水潜伏”：浅水静止时显著降低可见度；
- 主动“死亡翻滚”：咬住目标后短时持续伤害，受重击可中断；
- 胜利路线：控制饮水点，迫使陆地生物在不利位置交战。

### 7.10 河马

- 原型：巨型领地生物；体型 5；两栖草食；
- 优势：生命高、冲撞强、水边压制；
- 劣势：转向和技能落空惩罚大；
- 被动“领地怒火”：水域领地内对侵入者提高威慑和稳定；
- 主动“直线冲撞”：锁定方向冲刺，撞到目标或障碍结束；
- 胜利路线：守住关键水域，利用体型迫使敌人互相争夺其他路线。

## 8. 随机物种规则

玩家物种从本局已生成阵容中抽取，因此玩家不会成为地图上不存在的额外种类。抽取权重遵循：

- 与本关生态区兼容；
- 至少有一条可行食物链；
- 对应移动域占地图有效面积不低于阈值；
- 连续死亡时避免连续三次抽到同一物种；
- 不保证强度平均，但长期各体型的出现率可控。

默认不提供三选一，否则会削弱“被迫适应随机身份”的特色。可在辅助难度中加入一次重抽，但会标记为辅助通关。

## 9. 局内经验与升级

当前可玩版本采用“击杀经验 → 自动生态适应”的局内成长。等级随本局结束清除，不写入永久存档，因此不会破坏下一局随机物种的公平性。

### 9.1 经验来源

造成最终击杀的个体获得完整经验，玩家与 AI 遵守同一规则。玩家近期伤害、血味、毒素或惊群影响过的目标，如果被第三方击杀，则获得完整奖励的 45% 作为生态助攻经验。助攻窗口会随伤害或控制类型持续 6–10 秒；同一目标只记录当前有效的玩家影响，避免重复结算。基础奖励按物种危险度区分：

| 被击杀物种 | 基础经验 |
|---|---:|
| 雪兔 | 18 |
| 青环蛇 | 27 |
| 赤狐 | 32 |
| 林鹿 | 38 |
| 灰狼 | 46 |
| 荒原猞猁 | 41 |
| 獠牙野猪 | 48 |
| 棕熊 | 75 |
| 草原野牛 | 82 |
| 巨角驼鹿 | 84 |
| 沼泽鳄 | 88 |
| 山林猛虎 | 96 |
| 披甲犀牛 | 122 |
| 领地河马 | 135 |

若目标已经升级，奖励按 `基础经验 × (1 + (目标等级 - 1) × 0.14)` 增加，避免高等级强敌与初始个体奖励相同。

### 9.2 升级门槛

最高等级为 8。当前等级升到下一级所需经验：

```text
所需经验 = 45 + (等级 - 1) × 32 + (等级 - 1)² × 5
```

Lv.1 至 Lv.8 的逐级门槛为 45、82、129、186、253、330、417。前两级较快，让小地图也能体验成长；后续门槛提高，防止大地图滚雪球过快。

### 9.3 每级成长

不再让所有物种共用同一成长曲线，而是依据生态定位分为六类。表中百分比按当前属性复利成长，护甲为每级固定增量。

| 成长类型 | 最大生命 | 攻击 | 速度 | 最大耐力 | 护甲 | 耐力恢复 |
|---|---:|---:|---:|---:|---:|---:|
| 生存适应 | +8.0% | +5.5% | +2.5% | +6.0% | +0.8 | +2.5% |
| 敏捷猎手 | +8.5% | +7.0% | +2.2% | +5.5% | +0.9 | +2.4% |
| 捕食进化 | +9.0% | +7.5% | +1.8% | +5.0% | +1.2 | +2.2% |
| 迁徙强化 | +9.5% | +6.0% | +2.1% | +6.5% | +1.1 | +3.0% |
| 重装成长 | +11.5% | +6.5% | +1.2% | +5.5% | +1.8 | +2.4% |
| 巨兽蜕变 | +12.0% | +7.0% | +0.8% | +5.0% | +2.2 | +2.0% |

升级时会立即补足新增的生命上限和耐力上限，另恢复新上限 30% 的生命与 42% 的耐力。小型物种的速度成长较高，巨兽的速度成长则受严格限制，避免高等级巨兽消除小型动物的逃生优势。升级不缩短技能冷却，也不改变攻击距离。

### 9.4 弱物种逆袭成长

逆袭不直接修改物种基础攻击，而是读取攻击者与目标的生态威胁差。威胁级由物种基础击杀经验映射为 1–5 级，并与体型差取较大值。只有目标处于低耐力或技能后摇破绽时，弱者才能触发部分穿甲和百分比生命伤害。

该规则与等级成长并行：升级仍提高生命、攻击、速度、耐力和护甲，但不会让雪兔成长为正面重装单位。高等级弱物种只是更有能力制造和抓住破绽，物种身份仍保持明确。

### 9.5 信息反馈

HUD 始终显示当前等级、精确生命、耐力、饱腹和经验数值。附近动物头顶显示“等级、物种、当前生命/最大生命”；命中目标时，屏幕上方显示独立目标血条。可逆袭目标使用金色血条、破绽类型和剩余时间；逆袭命中显示额外伤害提示。击杀事件明确显示获得的经验，升级时给出中央提示和音效。

## 10. 内容制作规范

新增物种必须复用基础组件，并完成以下验收：

- 玩家与 AI 使用同一场景和数值；
- 有完整的食物、天敌和目标标签；
- 主动技能有前摇、命中、后摇、冷却、AI 使用条件；
- 在至少两个生态区可运行，或明确标记为领域限定；
- 能被至少一种其他生物克制，也至少有一种可靠优势；
- 自动生态测试 100 局中，首杀率和最终存活率不出现极端异常；
- 不依赖独占系统代码即可加载。
