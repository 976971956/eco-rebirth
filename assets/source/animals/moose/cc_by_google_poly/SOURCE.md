# Moose reference provenance

- Title: `Elk`
- Creator: Poly by Google
- Source: https://poly.pizza/m/93ddInBKzDw
- License: Creative Commons Attribution 3.0 Unported
- Published: 2017-09-27
- Source listing: approximately 1k triangles / 450 vertices, OBJ/GLTF
- Access checked: 2026-08-16

The production GLBs are generated by `tools/blender/build_cinematic_moose.py`.
They retain the project's 22-bone runtime contract while rebuilding a bull
moose's high shoulder, deep chest, sloped rump, very long articulated legs,
elongated overhanging muzzle, throat bell, split hooves and broad palmate
antlers. The linked elk model is used only to cross-check cervid proportion.
