# Zebra reference provenance

- Title: `Zebra`
- Creator: Poly by Google
- Source: https://poly.pizza/m/8Ut7mhb-aqK
- License: Creative Commons Attribution 3.0 Unported
- Published: 2017-09-25
- Source listing: 936 triangles / approximately 1.25k vertices, OBJ/GLTF
- Access checked: 2026-08-16

The production GLBs are generated by
`tools/blender/build_cinematic_zebra.py`. They retain the project's 22-bone
runtime contract while rebuilding an adult plains zebra's equine rib cage,
long head and neck, upright mane, surface-following black-and-white stripes,
single hooves and black tail switch. The linked model is used only to
cross-check silhouette and proportion.
