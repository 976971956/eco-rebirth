# Eco Rebirth repository instructions

- For every task in this repository, read and follow `.agents/skills/eco-rebirth-godot/SKILL.md` before changing files.
- After a modification is complete and its required checks pass, automatically create a scoped Git commit and push the current branch to its configured GitHub remote unless the user explicitly says not to.
- Never include unrelated user changes, build output, Godot cache files, credentials, signing files, or local IDE state in a commit.
