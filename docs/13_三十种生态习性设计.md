# 三十种生态习性设计

## 1. 设计目标

生态习性是独立于主动技能和战斗被动的第三层能力。它让弱小物种拥有稳定的生存目标，也让强势物种必须围绕自己的食物、地形和活动时段行动，而不是所有动物都只靠追击和换血。

每种动物的循环统一为：

1. 受伤或力竭后判断附近威胁；
2. 寻找本物种偏好的食物，不透视读取全地图资源；
3. 在主场、掩体、天气、昼夜或合适猎物体型下获得强化收益；
4. 进食后获得短时战术状态，再决定撤离、隐藏、防守或继续狩猎。

同一动物只能从同一食物点或同一具尸体触发一次习性。资源再生后仍可正常进食，但不会重复获得习性、经验和额外恢复，因此最优策略是迁徙和探索，而不是守点刷取。

## 2. 统一规则

| 规则 | 当前实现 |
|---|---|
| 基础触发 | 进食本物种偏好食物，额外恢复最大生命、最大耐力并降低饥饿 |
| 主场强化 | 食物位于物种主场或熟悉区域时，恢复与饱腹额外提高 20% |
| 特殊强化 | 满足掩体、受伤、天气、昼夜或猎物体型条件时，额外提高 25% |
| 双重强化 | 主场和特殊条件同时满足时，基础恢复共提高 45%，状态持续时间再提高 12% |
| AI 使用 | 生命低于物种独立阈值时，AI 会先排除危险尸体和高危热点，再选择可达的偏好食物 |
| 玩家引导 | 生命、耐力或饥饿进入风险区后，生态本能显示 52 米内最近安全资源的方向、距离和强化等级 |
| 适应经验 | 首次触发基础 2 点，主场与特殊条件各加 1 点，部分觅食物种另有见闻奖励 |
| 公平性 | 玩家和 AI 使用同一套触发、恢复、状态和单资源限次规则 |

五种短时状态：

- **轻捷**：移动速度提高 8%，冲刺耐力消耗降低 18%；
- **调息**：脱战后的耐力恢复提高 30%；
- **守势**：承受伤害降低 10%，击退强度降低 18%；
- **猎性**：普通攻击伤害提高 8%；
- **匿踪**：其他动物发现自己的有效距离降低 24%。

这些状态只持续约 3.8–7 秒，不叠层，也不替代物种原有的战斗被动和主动技能。

## 4. 雪兔的完整获胜路线

雪兔不再只有逃跑一种行为：

1. 开局沿古木林地和日照草原交界寻找嫩草，用觅食经验升级；
2. 受伤后不要直线逃到地图边缘，改为进入草丛附近的草堆触发“草窟反刍”；
3. 主场与草丛双重强化时，额外恢复约 11.6% 最大生命、17.4% 最大耐力，并获得轻捷；
4. 用轻捷离开原食物点，把追兵带向第三方、主场反制区或新的草丛；
5. 同一草堆不能重复触发习性，必须继续迁徙，利用多个资源点组成生存路线；
6. 终局保留主动技能和足够耐力，等待强敌力竭后通过伏击、环境反制或生态借力完成击杀。

这条路线让雪兔依靠地图知识、资源规划和第三方冲突取得胜利，仍保持正面战斗弱小的物种身份。

## 5. 验收标准

- 30 种物种全部拥有唯一名称、触发食物、恢复数值、短时状态和可读说明；
- 雪兔在草原草丛进食嫩草时实际获得约 11.6% 生命与 17.4% 耐力额外恢复；
- 雪兔吃落果不能错误触发草窟反刍；
- 同一动物重复取食同一资源不会再次触发习性或经验；
- 低血 AI 会寻找自己的偏好资源，并避开不安全尸体及非紧急情况下的高危热点；
- HUD、随机物种简报和自由模式选种页都会显示习性名称、说明或当前状态；
- 习性不得修改地图碰撞、出生规则、存档结构或物种基础面板。
